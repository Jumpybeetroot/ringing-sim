How it Works

This simulator uses a time-domain numerical integrator to model the 3D printer as a mass-spring system. It generates a kinematic toolpath (decelerating into a corner, turning, and accelerating away), passes that target through Klipper's exact Input Shaper time-delay algorithms, and then simulates the physical toolhead's attempt to follow that shaped command.

Understanding the Visualization

Top-Down Trace: An overhead view of the nozzle path. The dashed line is the ideal G-code path.

Peak Width: If Peak Width > 0, the simulator draws multiple lines to represent a "blurry" band of different vibration frequencies happening simultaneously. Narrow shapers (like MZV) will fail to cancel all the lines, while wide shapers (like EI) will pull them all together.

Corner Smoothing: Notice how aggressive shapers (like 3HUMP) eliminate ringing but "round off" the sharp corner by cutting inside the ideal path.
